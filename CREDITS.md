## Project code and generated content

- Facility geometry, props and mission layouts: `src/levels/`.
- Lab-coat staff and player rigs: `StaffModel.js` and `ResearcherOperator.js`.
  The creature and other procedural character parts use `CharacterFactory.js`.
- Weapons: procedural first-person viewmodel and third-person held weapon.
- Environment textures, normal/roughness maps, character bump detail and
  atmosphere textures: generated by the project code.
- Custom GLSL effects: heat shimmer, dissolve, pulse/weak-point glow,
  power-dependent lighting and screen grading/danger effects.
- Music, ambience, effects and PA chimes/sirens: synthesized with the browser
  Web Audio API in `AudioManager.js`. No external audio library (e.g. Howler.js)
  is used. PA wording appears as captions; no spoken dialogue plays.
- Warning favicon: project-created `public/favicon.svg`.

Contributors should identify any tutorial/code sources used for this work;
none should be inferred from the procedural implementation alone.
